envProxyOptions() → {object}

Description:

  • Resolve the per-protocol proxy from the environment for useEnvProxy.

    EnvHttpProxyAgent reads only HTTP(S)_PROXY, but axios — via proxy-from-env, which is what these call sites used to go through — falls back to ALL_PROXY when the protocol-specific variable is unset. formDataBody(form) → {PassThrough}

Description:

  • Turn a form-data instance into a stream undici can use as a request body.

    form-data emits string chunks; a PassThrough yields the Buffers undici requires and preserves streaming backpressure.

    A source failure mid-upload (a symbolication file that disappears, an I/O read error) is re-emitted by combined-stream as error on the form, and pipe() does not carry that to its destination. With no listener the event became an uncaught exception and took the API or jobserver process down. Forwarding it by destroying the body surfaces the failure on fetch's request body, so it reaches the caller's callback — which is what got did, as an UploadError on the request.

    NOT stream.pipeline: form-data is a legacy (combined-stream) readable, and pipeline's end-of-stream tracking never ends the destination for a form whose parts are all buffers or strings, so such an upload hangs forever. pipe handles it correctly; only the error path needs adding.

Source:
  • utils/countly-request/index.js, line 369
Parameters:
Name Type Description
form object

a form-data instance
Returns:

the request body stream

Type
